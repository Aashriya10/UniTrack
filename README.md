# UniTrack — University Information Management System

UniTrack is a Java-based application designed to manage university information. This project is currently under development as part of my learning journey in software development.

## Features

- Store and manage university information.
- Represent university details using Java classes and objects.
- Display university names, programs, and status.
- Store university data in a text file.
- Database integration using Java.

## Technologies Used

- **Language:** Java
- **Build Tool:** Apache Maven
- **Database:** SQLite (if this matches the database configured in the project)
- **IDE:** IntelliJ IDEA
- **Version Control:** Git and GitHub

## Getting Started

### Prerequisites

- Java Development Kit (JDK)
- IntelliJ IDEA or another Java IDE
- Apache Maven support

### Run the Project

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Allow Maven to load the dependencies listed in `pom.xml`.
4. Locate the main Java class containing the `main()` method.
5. Run the application.
